# Open Volume — Media + Editorial Component System

## Purpose
The component system should allow Open Volume to publish real programming and editorial without forcing every story, artist, place, or experience into the same visual template.

## Components

### MediaFrame
A neutral production-media container supporting:
- still images
- video with poster frames
- wide, cinematic, portrait, and square ratios
- deliberate placeholders while production media is unavailable

MediaFrame must not impose a recurring desert, cave, synthetic-world, or other thematic background. Content supplies the world; the brand supplies the frame.

### StoryCard
Designed for Open Volume Stories:
- category
- optional date/author metadata
- title
- excerpt
- media
- editorial status

Cards should be image-led when imagery is meaningful and typography-led when it is not. Do not fill empty inventory with generic stock.

### ExperienceCard
Designed for performances, sessions, live/hybrid programming, destinations, and worlds:
- status
- format
- artist(s)
- place/date when public
- summary
- hero media
- clear CTA

Development-state cards must not imply an announced artist, venue, world, date, partner, or production capability.

## Resonance Aperture
The aperture remains an approved **secondary** visual device, but it is intentionally **not coded yet**. Its geometry should be derived only after the canonical Resonance 01 production vector is present in the repository. Do not approximate the mark with CSS or redraw it from reference imagery.

Once implemented:
- default is off
- use only for meaningful reveal / transition / spatial emphasis
- avoid ubiquity
- keep compositions quieter when the aperture is prominent
- respect reduced-motion settings

## Draft content
The launch-content fixtures are editorial concepts used to exercise the component system. They do not represent published reporting or announced programming.

No fixture should invent:
- artist participation
- a public venue/destination
- a world identity
- a sponsor
- a date
- a capability not yet production-ready
