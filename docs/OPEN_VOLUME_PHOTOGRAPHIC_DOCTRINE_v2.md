# Open Volume — Photographic Doctrine v2

## Status
**Locked launch-era media standard**

This document supersedes any looser image-generation interpretation that treats Open Volume as "premium EDM imagery."

The governing principle is:

> **Electronic-music photojournalism elevated by world-class production design.**

Open Volume should look like a real electronic-music culture and production platform photographed by exceptional music, editorial, architectural, and documentary photographers. It should not look like CGI nightlife, a luxury hospitality campaign, a metaverse concept, or generic festival advertising.

## 1. Three-second category test

Every launch image must establish **electronic music / EDM culture within roughly three seconds** without relying on logo or copy.

At least one of the following should make the category legible:
- DJ / producer at decks or live electronic rig
- vocalist or collaborator inside a clearly electronic performance
- audience visibly oriented toward an electronic performance
- recognizable club / festival / production infrastructure
- soundcheck, rehearsal, FOH, lighting, camera, stage, or technical context that clearly belongs to electronic music
- venue architecture transformed specifically for an electronic-music production

Reject imagery that could just as easily be:
- a cocktail party
- luxury hospitality
- generic nightlife
- a gallery installation
- a jazz/lounge event
- a fashion party
- speculative technology advertising

## 2. Reference functions, not imitation

Useful external references include Boiler Room, Mixmag, Resident Advisor, Cercle, credible festival photography, and strong concert/event photojournalism.

Use them for **functional lessons**, not aesthetic copying.

### Boiler Room
Use as a reference for:
- performer/audience proximity
- believable booth placement
- physical crowd logic
- sweat, obstruction, imperfect sightlines
- real club energy
- people behaving independently rather than posing

### Mixmag / club photojournalism
Use as a reference for:
- awkward but real crops
- flash and mixed exposure
- blocked faces
- strange expressions
- fashion and individuality
- movement and social behavior
- photographs that feel incidental to the event rather than staged for the camera

### Resident Advisor
Use as a reference for:
- scene specificity
- local cultural character
- venue identity
- electronic-music credibility
- editorial restraint

### Cercle
Use as a reference for:
- place becoming part of the creative premise
- architectural scale
- destination anticipation
- production that remains physically believable
- artist and environment staying in a coherent spatial relationship

### Festival / concert photography
Use as a reference for:
- barriers
- walkways
- truss
- crowd lanes
- stage access
- imperfect density
- daylight and weather
- real scale and production logistics

## 3. Reality-first production logic

Every scene must be physically stageable.

Check:
- truss and speaker placement
- DJ booth height and orientation
- crowd access and barriers
- sightlines
- cables, cases, monitors, rails, stage edges
- lighting sources
- venue dimensions
- performer location
- camera position

If a knowledgeable producer, photographer, DJ, venue operator, or fan would immediately ask "how could that exist?", reject it.

## 4. Camera must have a plausible location

Every image should imply a real photographer position.

Valid examples:
- press pit
- crowd floor
- stage wing
- behind the booth
- balcony
- FOH
- production floor
- backstage
- loading dock
- rehearsal room
- drone / aerial when explicitly intended

Avoid impossible floating viewpoints and geometry chosen only because it looks dramatic.

## 5. Human realism

People are not decorative texture.

### Crowd behavior
A real crowd contains mixed behavior:
- watching the artist
- dancing
- talking
- moving through the room
- filming
- checking on a friend
- looking sideways
- reacting to a drop
- waiting at the edge
- partially blocked by other people

The **overall spatial attention must still make sense**. If the performer is the obvious focal point, a significant portion of the visible audience should plausibly relate to that focal point.

### Identity diversity
Across the library intentionally vary:
- age
- gender presentation
- skin tone
- ethnicity
- facial structure
- hair color
- hair length
- hair texture
- body type
- wardrobe
- role
- social grouping

Do not create a recurring "Open Volume person."

### MAEVRA exclusion
**MAEVRA appears only when explicitly requested.**

Generic female performers must not drift toward MAEVRA's recognizable combination of:
- warm olive / freckled complexion
- dark brunette short textured shag / pixie family
- lean athletic silhouette
- restrained edgy synthetic-artist styling
- similar facial structure / gaze / persona

For any generic female performer, deliberately vary at least three major visual traits away from MAEVRA.

## 6. Photographic imperfection is desirable

Real music photography is not perfectly clean.

Allow when plausible:
- foreground obstruction
- shallow focus
- motion blur
- blown highlights
- deep shadows
- uneven exposure
- grain
- partial faces
- imperfect framing
- lens flare
- off-center composition
- stage clutter
- cables and cases
- security / crew / barriers
- empty pockets in a crowd

Do not "correct" every image into commercial perfection.

## 7. Lighting doctrine

There is **no default Open Volume photographic grade**.

Lighting must come from the scene, venue, time of day, or actual production design.

Required range across the library:
- true daylight
- overcast daylight
- blue hour
- tungsten interior practicals
- sodium-vapor urban light
- saturated red production light
- cool cyan / blue
- deep monochrome color washes
- projection-only light
- neutral rehearsal / work light
- hard side light
- selective white spotlight
- mixed practical + stage light

### Explicitly avoid recurring defaults
Do not repeatedly fall back to:
- golden-hour luxury
- amber night lighting
- dark smoky room + white beams
- blue-magenta "EDM" shorthand
- perfect haze
- symmetrical light fans
- glowing rings / portals

Haze is a tool, not a brand signature.

## 8. Environment doctrine

Variation must remain inside the EDM production spine.

Strong territories:
- intimate club
- warehouse
- industrial venue
- architectural hall
- theater / black box
- rooftop
- urban exterior
- open-air destination production
- festival field
- contemporary cultural venue
- rehearsal room
- studio / soundstage
- backstage / loading / production areas

Use destination imagery only when the electronic-music production remains the reason the frame exists.

Avoid:
- resort social scenes
- cocktail-party imagery
- lounge-coded environments
- gallery-first installations
- luxury travel imagery with incidental music
- sci-fi environments
- speculative architecture
- metaverse shorthand

## 9. Six launch image buckets

All launch generation should map to one of these six buckets:

### 1. DJ / producer performance
- behind booth
- crowd-level
- stage wing
- intimate club
- larger production

### 2. Vocalist + electronic performance
- clearly tied to electronic production
- distinct casting
- real interaction with DJ / producer / crowd
- no default synthetic-artist archetype

### 3. Audience / culture
- clear performer/crowd spatial logic when stage-facing
- friendship, fashion, movement, anticipation, release
- fewer clearly visible faces when density makes duplication risk high

### 4. Venue / architecture as part of production
- architecture supports the music
- not empty concept-art spectacle
- real rigging and staging

### 5. Production process
- soundcheck
- rehearsal
- lighting programming
- FOH
- camera crew
- stage build
- artist/creative discussion
- production details

### 6. Flagship scale / destination
- large-scale event
- destination or architectural reveal
- music remains central
- production infrastructure must be credible

## 10. Asset mix

Do not build the launch library as a collection of hero renders.

Target mix:
- 25–30% performance
- 15–20% audience / culture
- 15–20% process / backstage
- 15% place / architecture
- 10–15% artist editorial
- 10% flagship scale / hero

A homepage should not reuse the same image, same subject, or same visual world twice unless there is a deliberate editorial reason.

Subpages should have distinct image identities.

## 11. AI-generation guardrails

Generated media is never final by default.

Reject for:
- duplicated faces
- cloned body types
- repeated hairstyles
- repeated wardrobe
- repeated crowd members
- malformed hands
- impossible fingers
- nonsensical gaze direction
- people facing away from the only obvious performer
- fake text
- fake sponsor marks
- impossible equipment
- malformed decks / mixers
- floating truss
- inconsistent shadows
- repeated architecture
- plastic skin
- over-smoothed faces
- excessive visual symmetry
- "rendered" surface quality

Crowd frames must receive a **200% zoom QA pass** before approval.

## 12. Production workflow

Every image moves through:

**Reference → Brief → Generate / Shoot → Select → Zoom QA → Retouch → Brand application if needed → Crop set → Placement QA → Approved**

Never publish a raw generation solely because it looks strong at thumbnail size.

## 13. Approval scorecard

An image must pass all critical items:

### Critical
- [ ] reads as electronic music / EDM culture
- [ ] photographically believable
- [ ] physically plausible
- [ ] human anatomy credible
- [ ] no duplicated or suspiciously repeated people
- [ ] crowd attention / eyelines make spatial sense
- [ ] no accidental MAEVRA resemblance unless intentional
- [ ] no invented Open Volume identity
- [ ] no fake readable signage
- [ ] survives 200% inspection

### Brand
- [ ] adds a visual territory not already overused
- [ ] does not default to amber / haze / white-beam / blue-magenta shorthand
- [ ] is not generic luxury hospitality
- [ ] is not generic sci-fi / metaverse imagery
- [ ] feels culturally current
- [ ] would be credible beside serious electronic-music editorial photography

### Usefulness
- [ ] has a defined role
- [ ] supports intended crop(s)
- [ ] does not duplicate another page's primary image
- [ ] can be retouched without rebuilding the scene

## 14. Master statement

When evaluating any Open Volume image, ask:

> **Does this look like a real moment inside a serious electronic-music culture property, photographed exceptionally well?**

If the answer is "it looks like a beautiful render," reject it.
