# Open Volume — Artist Casting Guardrails v1

## Core rule
**MAEVRA appears only when MAEVRA is explicitly requested.**

Open Volume's visual library must not accidentally converge on MAEVRA as the default female electronic artist.

MAEVRA has a deliberately defined likeness and visual identity. Repeatedly generating adjacent performers would weaken both:
- Open Volume's sense of a broad music culture
- MAEVRA's distinctiveness as an artist/IP property

## MAEVRA exclusion for generic casting

Unless a brief explicitly says **MAEVRA**, generic Open Volume performers should avoid combining MAEVRA's defining visual cluster:
- late-20s / early-30s presentation
- warm olive freckled complexion
- green/hazel-eye look
- dark brunette short textured razor shag / grown-out pixie
- lean athletic build
- the established restrained, edgy synthetic-artist styling

A generic subject can share an individual trait, but should not reproduce the overall recognizable combination.

## Casting diversity principle

Across the library, intentionally vary:
- gender presentation
- age range within plausible music-scene casting
- skin tones and cultural backgrounds
- hair color, length and texture
- body types
- wardrobe language
- performance roles
- DJ / producer / vocalist / instrumentalist / collaborator
- solo vs ensemble presence

The goal is not quota-like visual tokenism. The goal is to portray a believable, globally varied electronic-music culture rather than one recurring synthetic archetype.

## Per-image brief requirement

Every artist-facing image brief must now specify one of:

### A. Named artist
Use only when the actual artist/character is intentional and approved.

### B. Fictional / generic performer
Define enough visual distinction to prevent accidental resemblance to MAEVRA or another recurring subject.

### C. Audience / anonymous culture
The individual is not the brand subject; avoid turning them into an accidental recurring character.

## Generic female performer safeguard

For any generic female electronic artist, explicitly vary at least **three** of the following away from MAEVRA:
- age presentation
- skin tone
- hair length
- hair color
- hair texture
- facial structure
- body type
- wardrobe silhouette
- makeup language
- performance persona

## Approval question
Before approving any generic performer image:

> Could a viewer reasonably assume this is MAEVRA?

If yes, the image is held, regenerated, or intentionally reclassified before publication.
