# Open Volume — Launch Image Library Plan v1

## Objective

Build a **50–75 image launch library** that supports the website, social launch, editorial, partner outreach, brand presentations, and owned-audience content without making Open Volume look like only a live-event producer.

The library should be produced in waves. The first target is **60 approved stills**.

## Library architecture

| Territory | Target | Primary value |
|---|---:|---|
| Live culture / club / festival | 16 | audience desire + cultural credibility |
| Artist / editorial | 10 | artist value + Stories |
| Place / destination / architecture | 9 | cinematic authorship + venue/partner value |
| Audience / culture | 7 | belonging + social energy |
| Process / backstage / rehearsal | 7 | capability + collaborator credibility |
| Recorded / cinematic / studio | 5 | platform breadth beyond live events |
| Believable hybrid / spatial media | 3 | future-facing flexibility |
| Hero-brand / explicit Open Volume | 3 | recognition + campaign identity |
| **Total** | **60** | |

The counts are guidance, not rigid quotas. Avoid producing filler simply to hit a category count.

## Territory specifications

### A. Live culture / club / festival — 16

Must include:
- intimate DJ booth / crowd relationship
- vocalist performance
- producer or live electronic collaboration
- dense nightclub floor
- medium-scale cultural venue
- festival artist/crowd exchange
- festival environmental wide
- unusual stage perspective
- daylight or golden-hour event
- nighttime large-scale event
- crowd-level view
- behind-artist stage view
- venue exterior / arrival
- strong architectural interior
- one aerial/top-down crowd geometry
- one partnership-facing venue hero

Do not let 16 images become 16 variations of a DJ facing hands in the air.

### B. Artist / editorial — 10

Mix:
- cinematic portrait
- candid preparation
- performer after/before set
- producer at work
- vocalist close-up
- fashion-forward artist portrait
- environmental portrait in a venue
- artist in daylight
- artist/collaborator interaction
- quiet editorial frame with no event spectacle

These should be capable of leading Stories articles.

### C. Place / destination / architecture — 9

Mix:
- extreme drone destination reveal
- rooftop/city
- coast/water
- contemporary cultural venue
- industrial space
- lush/natural location
- modern interior
- exterior at blue hour
- place with no active performance

The last item is important: Open Volume should demonstrate taste in **places**, not only stages.

### D. Audience / culture — 7

Include:
- friendship
- fashion
- dancing
- anticipation
- crowd reaction
- discovery/social interaction
- post-performance or transitional moment

Not every audience image should be facing the performer.

### E. Process / backstage / rehearsal — 7

Include:
- lighting/programming
- camera/film crew
- rehearsal
- artist/creative-director conversation
- soundcheck
- production detail
- backstage anticipation

Capability should appear serious, not like an equipment rental company.

### F. Recorded / cinematic / studio — 5

Needed to prevent “live-events company” perception.

Include:
- studio performance
- cinematic performance capture
- controlled soundstage
- artist/director camera setup
- intimate recorded session

### G. Believable hybrid / spatial media — 3

These must remain physically credible.

Examples:
- projection mapped into real architecture
- large-format LED/spatial media inside a real venue
- physically plausible remote/multi-location participation

Avoid fantasy locations and impossible architecture.

### H. Hero-brand / explicit Open Volume — 3

Use actual production identity in post.

Suggested:
1. extraordinary but believable venue arrival
2. live/venue hero with subtle Open Volume stage presence
3. campaign/editorial hero where identity is integrated into real media/architecture

Every approved image should be tagged for:

## Production quality threshold

Do not approve an image solely because it is aesthetically attractive.

Each final still must be:
- high-resolution
- anatomically credible
- physically coherent
- free from invented brand marks
- clear of legible fake sponsor/venue names unless intentionally designed
- retouchable
- crop-flexible enough for its intended channel
- consistent with the locked Visual Reference System

## Asset state

Each image should move through:

**Concept → Generate/Shoot → Select → Retouch → Brand application if needed → Crop set → QA → Approved**

Never treat raw AI generation as a final production asset.


## v2 photographic production constraints

This plan is governed by `OPEN_VOLUME_PHOTOGRAPHIC_DOCTRINE_v2.md`.

### Non-negotiable production direction

The library must read as **electronic-music photojournalism elevated by world-class production design**.

Do not use "premium EDM," "cinematic EDM," "immersive," or "futuristic" as sufficient art direction. Those terms have repeatedly collapsed generation toward synthetic defaults.

### Required visual spread

Across each production wave, deliberately vary:
- lighting source and color world
- venue type
- camera position
- artist demographics
- performer role
- crowd density
- time of day
- photographic genre

No wave should be dominated by:
- golden hour / amber
- dark haze + white beams
- blue-magenta club light
- attractive face-forward crowds
- brunette female performer archetypes
- giant LED / portal / ring spectacle

### No-repeat placement rule

For launch website placement:
- no primary image should appear twice on the homepage
- no subpage hero should reuse the homepage hero
- no two adjacent sections should use the same subject archetype or venue world
- social covers should not simply reuse website hero crops unless intentionally part of one campaign

### Approval gate

Every candidate entering the approved library must pass:
1. three-second EDM category test
2. physical-production plausibility
3. crowd / gaze logic review
4. MAEVRA-exclusion review when applicable
5. 200% zoom inspection
6. distinctiveness check against the existing approved library
