# Open Volume — Launch Asset Master Checklist v1

## Purpose

This is the production control sheet for the final public-launch sprint. It converts the launch strategy into a finite set of assets and separates **launch blockers** from post-launch expansion.

Status vocabulary:
- **DONE** — final and approved
- **REVISION** — exists but does not yet meet launch standard
- **MISSING** — not yet produced
- **HOLD** — intentionally deferred beyond public launch

### Photo production rule
Do not generate these as a generic batch. Each asset receives an isolated brief containing:
- cultural-position score on elevated ↔ raw spectrum
- sonic context
- exact venue/environment
- performer casting
- audience behavior
- lighting source/color system
- camera position/lens language
- crowd-density strategy
- intended placement/crop
- explicit visual defaults to exclude
- final retouch/QA plan

## Final launch test

Open Volume is ready to launch when the public surface communicates:

**electronic music + premium execution + cultural credibility + production/platform breadth + a reason to follow what comes next.**

It is not ready if the surface primarily reads as:
- an event promoter
- luxury nightlife
- a generic festival brand
- a synthetic/AI-art project
- a tech-demo company
- a single-subgenre label
