# Open Volume — Identity + Media Integration Plan

## Objective
Move the public site from launch-shell placeholders to a recognizable Open Volume experience using the approved production identity and the first four locked visual directions.

## Identity source
Use the approved Resonance 01 production identity. The raster exports in `/public/brand` are interim production-ready derivatives of the approved identity artwork and must not be redrawn or reinterpreted.

Permanent SVG masters should replace these raster exports when the canonical vector package is available in repository-ready form.

## Initial media map
- OV-IMG-001 — Destination Reveal: destination / partnership / scale
- OV-IMG-002 — Club Intimacy: cultural credibility / proximity
- OV-IMG-003 — Electronic Vocalist Hero: artist-led value
- OV-IMG-004 — Premium Club Crowd Culture: audience / belonging / premium nightlife

## Website placement
- Header/footer: approved horizontal identity lockups
- Homepage hero: text-first brand statement with restrained identity, not a full-screen event image
- For Artists: OV-IMG-003
- For the Audience: OV-IMG-004
- Open Volume Presents: OV-IMG-001
- Stories / Perspective 01 support: OV-IMG-002 or OV-IMG-004 depending crop
- Partners: OV-IMG-001 as the strongest venue/destination-facing visual

## Guardrails
- Do not add generated or invented logos to source images.
- Do not imply the pictured venue, artist, crowd, or event is an announced Open Volume production.
- Use launch imagery as directional/editorial brand media until real Open Volume production photography exists.
- Do not over-brand every image.
- Keep World 01 / fantasy imagery out of the launch site.
