# Open Volume

Public brand and launch-site repository for Open Volume.

## Brand principle
Open Volume is music-first. The public experience should communicate artistic, creative, cultural, and commercial value without reducing the brand to a single venue, world, technology, or production format.

## Stack
- Next.js
- TypeScript
- Tailwind
- repository-backed content abstraction with a future CMS adapter path

## Local setup
1. Copy `.env.example` to `.env.local`.
2. Set `NEXT_PUBLIC_SITE_URL` and `NEXT_PUBLIC_CONTACT_EMAIL`.
3. Add confirmed social profile URLs only when those accounts are live.
4. Connect `OPEN_VOLUME_JOIN_WEBHOOK_URL` before enabling public audience capture.
5. Run `npm install` and `npm run dev`.
