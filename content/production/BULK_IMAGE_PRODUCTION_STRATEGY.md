# Open Volume — Bulk Image Production Strategy

## Decision
The first four images were produced individually to calibrate quality and lock the visual system.

From this point forward, **do not continue one-by-one image production by default**.

The remaining launch library should be produced in **small intentional batches**, then curated aggressively.

## Why
Open Volume has broader launch priorities:
- finish the website
- get social profiles online
- begin audience building
- publish the first Stories/editorial content
- establish owned-audience capture

Image production should support those goals rather than consume the whole launch schedule.

## Batch model

Produce **6–10 candidates per batch** around distinct territories, then select only the strongest.

Recommended next batches:

### Batch A — Artist / editorial / studio
- producer at work
- male electronic artist
- female artist clearly non-MAEVRA
- duo/collaboration
- rehearsal
- studio performance
- editorial portrait
- cinematic recorded session

### Batch B — Place / venue / architecture
- rooftop
- contemporary cultural venue
- industrial venue
- coastline/water
- urban night
- place-only image
- daylight festival environment
- venue arrival/exterior

### Batch C — Process / backstage / production
- lighting programming
- camera crew
- soundcheck
- rehearsal
- creative-director conversation
- backstage anticipation
- technical detail
- production monitor / stage prep

### Batch D — Believable hybrid / spatial media
Only after A–C have sufficient depth.
Keep every environment physically plausible.

## Selection rule
A batch may produce 8 candidates and yield only 2–4 approved images.

That is expected.

Do not lower the approval threshold to preserve sunk generation effort.
